# Corg.ly хэрэглэгчийн баримтжуулалт ба UX бичвэр

Анхны санал асуулгаа үүсгэж нэг санал өгөх 8 алхамтай Tutorial, Slack холбох / санал өгөх / үр дүн шалгах 3 How-to, 5 HTTP endpoint-ийн Reference болон дотоод хайлт нэмэв. Алдаа, хоосон төлөв, эхлэх зөвлөмжийн бичвэрийг богиносгож, хэрэглэгчийн хийх үйлдлийг тодорхой болгов.

## Баталгаажуулалт

- `python3 checks.py`: 16/16 функционал шалгалт.
- HTTP болон индексжих агуулгын нэмэлт шалгалт: 14/14 (`HTTP_checks.json`).
- Mock Slack шалгалтаас тусад нь бодит Slack илгээлтийг хэрэглэгчийн дэлгэцийн зургаар баталгаажуулсан: Corgly Lab / #new-channel, Corgly Survey апп, Даваа 1 ба Мягмар 0. Word тайлангийн 11-р хэсэгт нотолгоотой.
- Автомат browser QA болон хэрэглэгч оролцуулсан readability туршилт хийгдээгүй.

## Номын шаардлагыг хэрэглэсэн нь

- Bhatti et al., Docs for Developers (2021), бүлэг 2, х.31–32: Tutorial 10-аас цөөн буюу 8 алхамтай; бүлэг 3, х.57–60: ажлын зорилгоор How-to-г тусгаарласан; бүлэг 5, х.92: reference-ийн бүтэц.
- Chinchilla, Tech Writing for SW Devs (2024), бүлэг 3, х.27–30: cognitive load багасгах, бичвэрийг товчлох, хэрэглэгчид хандах; бүлэг 4, х.50: өмнөх/дараах өөрчлөлт; бүлэг 5, х.60: хэмжилт; бүлэг 7, х.92: prerequisite-ийг урд нь байрлуулах.
- Номын бүлэг, хуудасны mapping-ийг Week 07 Lab Guide-аас авсан. Номын бүтэн эх олгогдоогүй тул шууд эшлэл гэж танилцуулаагүй.
- Diátaxis: https://diataxis.fr/ — Tutorial, How-to, Reference-ийг тусдаа зорилготой байхаар зохион байгуулсан.
